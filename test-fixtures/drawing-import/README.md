# FacadeFlow demo input pack

One invented, non-production example represented in several formats.

- PNG: photographed/scanned-style image input test.
- PDF: technical drawing import and page-rendering test.
- SVG: vector reference for visual inspection.
- ASCII DXF: minimal valid line-geometry interchange example; not production CAD.
- CSV: product schedule import concept.
- simulation JSON: safe structured import example.

Product: DEMO-W01, REF-04, 1400 x 1200 mm, quantity 1.

All files are SIMULATION ONLY, machineReady=false, and require human approval. No DWG is included because a fake proprietary binary would not be a valid or useful test artifact.
