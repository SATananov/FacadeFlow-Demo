## Failure-driven development

`realTrainingFailureRouter` routes a real failure to the layer that actually owns it:

- document structure failure → `REAL_DATA_EXTRACTOR`;
- prompt-language failure → `NEXT_PROMPT_CORPUS`;
- construction semantic/drawing failure → `AI05`;
- missing profile knowledge → `PROFILE_DATA`;
- missing confirmation → `HUMAN_REVIEW`.

A new prompt Corpus is therefore created **only after a real prompt-language failure**, not because the corpus number should increase.

## Model-learning boundary

A human-confirmed example may become eligible for a curated dataset. It does not automatically change LLM/model weights.

- raw private offer text in regression: NO;
- client identity in regression: NO;
- automatic training promotion: NO;
- automatic model-weight update: NO;
- automatic production geometry: NO;
- rules validated: NO;
- machine ready: NO;
- production approved: NO.
