# PHASE 06B.2.3 — UNIFIED VISUAL POLISH ACCEPTANCE

Scope: visual/UX only. No geometry, CAD tool, AI state, import interpretation, machine/export or production behavior changes.

Acceptance:
- Every top-level workspace uses the same FacadeFlow technical header language.
- The Nadezhda logo is visible at the far right of every top-level workspace header.
- Normal visible text in Constructor, Import, Catalogue and Help has readable contrast.
- Disabled controls may be muted; ordinary content must not inherit pale shell text.
- AI uses exactly one primary vertical workspace scrollbar. The status rail does not create a second scrollbar.
- AI Human Review stays sticky on desktop and becomes a normal block on narrow layouts.
- Constructor, Import, Catalogue and Help each have one primary workspace scroll; functional CAD/document panes may retain local scrolling where required.
- Former full-screen modal sections remain first-class workspaces and do not reveal or scroll the hidden FacadeFlow page underneath.
