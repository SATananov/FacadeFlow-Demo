# PHASE 06C.1.1 — Guided Builder UX Acceptance

## Goal
Make the AI intake behave like a guided product technologist instead of a project-card gallery.

## Acceptance
- Job context is compact and keeps all flexible contexts, including **Единично изделие**.
- Selecting a context opens **Води ме / описание** immediately.
- All four input modes remain available and switchable.
- Guided product fields remain the 06C.1 structured source of truth.
- The right inspector shows a live product summary before a proposal is prepared.
- The locked 06B.2 visual/safety acceptance markers remain present.
- Human review, rules validation, source evidence and machine-output locks remain unchanged.
- No network, persistence, AI inference, automatic geometry or production export is introduced.
