# AI04 — Human-Approved Proposal → Editable Constructor Geometry V1 — Bundle Acceptance

AI04.1–AI04.4 establish the first explicit bridge from reviewed AI intelligence to editable constructor geometry.

## Workflow
`Prompt / Documents → Product Intent → AI03 proposal → Human Review → explicit AI04 acknowledgement → editable Custom Product Designer draft → normal constructor validation / human review`

## Critical distinction
AI04 is not automatic geometry acceptance. AI03 may generate a proposal, but AI04 can create constructor geometry only after the proposal has been reviewed by a human and the user separately requests the handoff.

## V1 scope
Supported:
- WINDOW / DOOR proposal geometry already representable by AI03 linear V1 topology;
- fixed + opening sash fields;
- vertical/horizontal linear dividers;
- exact LEFT/RIGHT and TURN/TILT/TILT_TURN preservation;
- exact catalogue profile matching only;
- editable Custom Product Designer draft with provenance.

Blocked/deferred:
- sliding sash / panel semantic conversion;
- automatic profile choice from system name;
- production formulas or machining rules;
- automatic constructor verification;
- machine export / machine-ready status.

## Safety lock
AUTO-GENERATED PROPOSAL = possible in AI03
HUMAN-APPROVED PROPOSAL = required
AUTOMATIC CONSTRUCTOR HANDOFF = NO
EDITABLE GEOMETRY DRAFT = YES, only by explicit human action
RULES VALIDATED = NO
MACHINE READY = NO
PRODUCTION APPROVED = NO
