# PROFILE DATA 03.1 — Visual Section Library Foundation

## Scope

PROFILE DATA 03.1 adds the first visual section knowledge layer for the Nadezhda / PRELUDE 60 human-confirmed measurements.

The visualizations are measurement schematics only. They explain the already confirmed full dimension, visible width and 22 mm zones for:

- `482.30` FRAME — `64 − 22 = 42 mm`
- `482.05` SASH — `78 − 22 = 56 mm`
- `482.21` MULLION — `84 − 22 − 22 = 40 mm`

## Safety boundary

The phase does **not** infer or claim the exact PVC profile contour from screenshots or catalogue images.

- exact CAD contour: **NO**
- automatic catalogue merge: **NO**
- automatic geometry overwrite: **NO**
- automatic production use: **NO**
- MACHINE READY: **NO**
- PRODUCTION APPROVED: **NO**

## UX

Projects → Sources → Nadezhda now includes a "Visual Section Library" panel. The user can switch between the three human-confirmed profiles and see a proportional schematic of the visible and deducted zones plus the confirmed formula and provenance.

The UI labels every drawing as schematic and not a production drawing.
